# Be™ Brooklyn Equine

A beautifully designed equestrian website for Be Brooklyn Equine at Prospect Park Stable, Brooklyn's historic stable since 1917.

## Overview

Brooklyn's only centrally located stable offering:
- Pony rides for toddlers (May–October, Sundays 1–3 PM)
- Riding lessons for all ages and skill levels
- Trail rides through Prospect Park's 3.5-mile bridle path
- After-school & summer programs
- Horse care education
